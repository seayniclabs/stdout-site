# Lore architecture map

_Generated by Lore. Use this to find which files/areas a change concerns before reading code._

- Frontend — Astro pages and components for dashboards, HUD, setup wizard, docs, status pages and incident UI
- Backend — Astro API routes and lib services handling scanning, diagnosis, monitors, ticketing sync and business logic
- Database — SQLite store with Drizzle schemas and migrations for tenant and central data
- Auth — Session auth, RBAC, licensing, password reset and middleware-based access control
- Integrations — AI diagnosis providers, email, Slack alerts, and ticketing connectors (GitHub, webhook)
- Infrastructure — Docker-based deployment and observatory monitoring/observability stack with sentinel agents
